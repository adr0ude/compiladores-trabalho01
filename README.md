# Trabalho Computacional 01

Atividade desenvolvida na disciplina de Compiladores, ministrada pelo professor Adonias Caetano de Oliveira, do curso de Bacharelado em Ciência da Computação do IFCE _Campus_ Tianguá, pela Equipe 05, composta pelos alunos Dhiego Cavalcanti, João Pedro Jácome, Letícia Reis, Luís Guilherme Ferreira, Maria Eduarda Araujo e Maria Luiza Pereira.

## Objetivo

O trabalho tem como objetivo revisar conteúdos relacionados a **Linguagens Regulares** utilizando a ferramenta **JFLAP**, além de utilizar uma linguagem de programação clássica para a implementação de um programa.

### Questão de Programação

Implementação de um programa que determina, para uma entrada de inteiro natural `n`:

- o fatorial;
- a sequência de Fibonacci; ou
- se o número é primo.

A implementação deve ser realizada em uma das linguagens a seguir:

- COBOL
- Smalltalk

**A equipe optou por implementar um programa que determina o fatorial de um número natural na linguagem de programação COBOL.**
